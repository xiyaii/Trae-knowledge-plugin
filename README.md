# Trae Ask - Trae 企业版智能问答助手

> 💡 **即刻获取答案，无需离开编辑器** - Trae Ask 是专为 Trae 企业版用户打造的智能问答助手，基于火山引擎知识库，提供开箱即用的技术问题解答能力。

***

## ✨ 核心特性

### 🎯 智能问答，精准匹配

- 基于火山引擎企业级知识库检索

### 💬 自然对话体验

- 支持多轮上下文对话（可配置保留最近 N 轮）
- Markdown 格式渲染，代码高亮清晰易读
- 中文输入法友好，避免选词时 Enter 误发送
- 一键清空对话历史，保持界面整洁

### 🔒 企业级安全

- **Trae 企业版专属**：校验订阅状态，
- 无需额外配置账号，一键验证即可使用

***

## 🚀 快速开始

### 1. 安装插件

在 Trae IDE 扩展面板中通过 VSIX 文件手动安装。

### 2. 验证企业版订阅

1. 点击左侧活动栏的 Trae Ask 图标（💬）
2. 点击「验证企业版订阅」按钮
3. 验证通过后即可开始问答

### 3. 开始提问

在输入框中输入你的技术问题，按 Enter 发送即可获得答案。

## ❓ 常见问题

**Q: 点击验证后提示"未购买企业版"？**
A: Trae Ask 仅面向 Trae 企业版用户，请确认你已登录 Trae 企业版账号。

**Q: 为什么返回"知识库未检索到相关内容"？**
A: 当问题与知识库内容相似度低于阈值（0.2）时会返回此提示，建议联系 Trae 技术支持确认。

**Q: 对话历史会保留吗？**
A: 对话历史仅保存在本地内存中，重启 IDE 后会清空。默认保留最近 10 轮对话用于上下文理解。

**Q: 需要配置 APIKey 吗？**
A: 不需要！APIKey 已安全存储在服务端，你只需验证企业版订阅即可使用。

**Q: 支持哪些平台？**
A: 支持 macOS（Apple Silicon & Intel）、Windows、Linux，与 Trae IDE 支持平台一致。

## 📋 命令面板

通过 `Cmd+Shift+P`（macOS）/ `Ctrl+Shift+P`（Windows/Linux）打开命令面板，输入以下命令：

- **Trae Ask: 打开问答** - 显示 Trae Ask 面板
- **Trae Ask: 清空对话** - 清除当前聊天记录
- **Trae Ask: 配置** - 打开设置页面

## 📊 运营看板（admin-service）

内置运营数据看板，供运营团队监控插件使用情况与知识库健康度。

### 功能特性

- **KPI 总览**：激活设备数、登录用户数、问答次数、DAU、平均检索得分、低分占比
- **环比分析**：自动对比上一周期，绿色↑/红色↓标识趋势（低分占比为反向指标）
- **数字动画**：KPI 卡数值 count-up 动画，sparkline 迷你折线展示趋势
- **日趋势图**：分组柱状图（安装/登录/问答）+ DAU 折线叠加，图例可点击切换显示
- **Top 文档**：横向条形图按命中次数排序，颜色按平均得分渐变（红/橙/绿）
- **低分问答**：支持搜索、表头排序、行展开详情、CSV 导出
- **暗色模式**：右上角按钮一键切换亮/暗主题，localStorage 持久化
- **骨架屏**：数据加载时 shimmer 动画，避免内容跳动
- **响应式布局**：自适应桌面/平板/手机

### 技术栈

- React 18 + TypeScript
- Recharts（图表）
- Framer Motion（动效）
- Vite 构建，产物通过 `go:embed` 打包进 Go 二进制
- 设计 Token 化（CSS 变量），支持亮/暗双主题

### 快捷操作

- **日期预设**：今日 / 近 7 天 / 近 30 天 / 近 90 天
- **自定义日期**：日期选择器
- **刷新按钮**：右上角手动刷新数据
- **主题切换**：右上角 ☀️/🌙 按钮
- **CSV 导出**：低分问答区右上角
